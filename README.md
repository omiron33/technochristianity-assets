# TechnoChristianity runtime assets

Full-resolution architectural model assets for [TechnoChristianity](https://technochristianity.com). This static repository serves the walkable churches while the website serves its pages and photograph galleries.

The `releases/2026-09-22/` directory contains four glTF model packages, their complete image and geometry dependencies, and the original attribution documents. Asset files retain their published bytes. Relative glTF references work within the release directory.

[`releases/2026-09-22/manifest.json`](releases/2026-09-22/manifest.json) records the byte length and SHA-256 digest of every model and attribution file. Release directories should remain immutable once published.
