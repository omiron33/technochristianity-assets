# The Faith of the Apostles · v2

Web media for the original Orthodox song and lyric film [The Faith of the Apostles](https://technochristianity.com/music/?work=faith-of-the-apostles).

- `faith-of-the-apostles.wav`: the original stereo, 48 kHz, 16-bit WAV master, unchanged.
- `faith-of-the-apostles.mp4`: a full-length 1920 × 1080, 30 fps H.264/AAC delivery copy transcoded directly from the approved v2 film master. The full-quality film is also [on YouTube](https://www.youtube.com/watch?v=GIqK4IMjw0g).
- `posters/faith-of-the-apostles.jpg`: a frame from v2 at 84.86 seconds.
- `manifest.json`: exact byte lengths, SHA-256 hashes and release provenance.

The [film source repository](https://github.com/omiron33/faith-of-the-apostles) holds scene code and measured lyric timing. The original recording is [on Suno](https://suno.com/song/2a8faba8-f258-473a-bd04-994c498f22bf). This is an original song, not a complete Scripture chapter or a liturgical text.

This dated release is immutable. Publish revised media in a new release directory. Source-code licenses do not automatically license the song recording or other separately credited assets.
